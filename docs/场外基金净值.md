# 场外基金净值

“场外联接 A/C”中的 5 组人民币联接基金在本站显示净值走势、均线、MACD、RSI、阶段涨跌幅和趋势参考。申赎状态、限额和分档费率独立加载，并列显示对应 A/C 份额；仍可打开天天基金查看公告和申赎规则。品种及新增接口见[资产分类与基金观察](资产分类与基金观察.md)。

## 数据与计算口径

- 来源：基金详情页实际引用的 `https://fund.eastmoney.com/pingzhongdata/{symbol}.js`。只以 JSON 解码数据变量，不执行 JavaScript。
- `Data_netWorthTrend` 的 `x` 按中国标准时间转为净值日期；`y` 是单位净值，`equityReturn` 是已公布的日涨跌幅。
- 最多返回最近 500 个净值日，成功结果缓存 5 分钟；获取时间保持为实际抓取时间。缺失数据或抓取失败显示错误。
- 以日涨跌幅倒推复权序列，末值对齐最新单位净值。常规净值比率与公布涨跌幅的差在两位小数舍入范围内时，使用实际净值比率，避免累积舍入误差；分红、份额折算等跳变日按公布涨跌幅调整，界面注明调整日数和来源精度限制。遇到涨跌幅缺失，只分析缺口之后的连续有效区间。
- 阶段涨跌幅以最新净值日为截止日，分别使用 7 / 30 / 90 个自然日前最后一条已公布净值作为基准。缺少基准时返回 `null`。
- 均线按日复权净值计算。周视图取每周最后一个已公布净值点，仍显示日均线；MACD、RSI按选定的日/周序列计算。周视图不构造周内高低价。
- 回撤是当前连续有效分析区间的最大回撤，界面同时显示区间起止日期。
- 不返回场内 OHLC、成交量、资金流、缠论或可执行买卖信号。QDII 净值可能延迟披露；实际申赎价格和确认时间依照基金规则。

## 接口

`GET /api/fund?symbol=050025`

- 输入：`symbol` 必须为 6 位 ASCII 数字；非法输入返回 HTTP 400。
- 返回：`symbol`、`name`、`source`、`source_url`、`fetched_at`、`history`、`latest`、`analysis`。
- `history`：`date`、`nav`、`change_pct`、`adjusted_nav`、`ma5`、`ma20`、`ma60`；不足计算窗口的指标为 `null`。
- `analysis`：趋势方向、阶段涨跌幅、日均线末值、最大回撤、分析区间和有效样本数。
- 上游请求或数据解析失败沿用服务的 HTTP 503 错误响应，不把失败转换为零净值或零收益。

验证：`py -3 -m unittest discover -s tests -p "test_fund_nav.py"` 和 `node --test tests/test_fund_nav_ui.cjs`。
